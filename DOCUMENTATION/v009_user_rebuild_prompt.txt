5. BUILD PHILOSOPHY — THIS IS THE MOST IMPORTANT TECHNICAL RULE
============================================================

Do NOT treat v009 as "adjust the existing jump heights."

The real Orlando MX footage shows CONTINUOUS MOTOCROSS TERRAIN.

The current build too often behaves like:

flat -> isolated mound -> flat -> broad smooth turn -> flat

The v009 target should behave like:

approach undulation
-> braking terrain
-> progressive face
-> rounded crest/lip
-> landing
-> berm/crossfall
-> compact exit
-> roller/rise
-> next obstacle

Each real section should be built as a TERRAIN SECTOR.

A sector may alter:
- local route/centerline alignment,
- longitudinal elevation,
- cross-track banking,
- outside berm height,
- inside rut/channel depth,
- track width,
- shoulder falloff,
- braking chop,
- acceleration rollers,
- jump toe,
- jump face length and curvature,
- lip/crest character,
- tabletop/gap only where supported by footage,
- landing position,
- landing grade,
- landing runout,
- transition into the next corner.

The existing J01-J12b / jump_profiles.json entries are editable scaffolding, NOT ground truth.
Move, replace, merge, split, or reclassify them if the footage requires it.

============================================================
6. TERRAIN AUTHORING METHOD
============================================================

Use the existing reproducible heightmap pipeline rather than hand-editing compiled binaries.

Prefer route-relative / Frenet-style sector construction:
- station s along the route,
- lateral offset t from centerline,
- smooth longitudinal windows,
- smooth cross-track profiles,
- C1/C2-continuous blends into untouched terrain.

Keep terrain outside the affected track corridor stable unless a real surrounding elevation change is needed.

For berms:
- create actual collision/heightmap banking,
- keep the inside preferred line lower,
- progressively raise the outside half,
- use a broad supporting berm rather than a thin vertical wall,
- taper banking in before apex and taper out after exit,
- allow multiple rideable lines.

For ruts:
- use shallow physical grooves only where appropriate,
- do not make deep wheel-catching trenches,
- align them with actual travel direction,
- supplement them with visual masks instead of relying on texture alone.

For jumps:
- give each major obstacle a unique profile,
- use smooth toe transitions,
- generally use progressive faces,
- use rounded/controlled lip transitions,
- use real downslope landings,
- avoid repeated identical 7-8 m faces and generic flat decks,
- avoid supercross-sharp lips unless the GoPro clearly supports them.

Starting construction envelopes may be used only as NON-SURVEYED authoring estimates:
- effective shaped racing width often ~7-10 m,
- visually cleared dirt can be wider, roughly ~10-16 m where appropriate,
- major berm rise roughly ~0.5-1.3 m where the footage supports a strong wall,
- meaningful bank angles roughly ~8-18 degrees,
- small crest/roller local relief roughly ~0.7-1.4 m,
- medium jump roughly ~1.5-2.5 m,
- major signature feature roughly ~2.3-3.5 m,
- jump faces can range roughly ~7-18 m,
- landings/runouts may be ~10-25 m.

These are starting ranges only. They are NOT measured dimensions. The GoPro proportions, riding rhythm, and in-game validation take precedence.

7. SECTION-BY-SECTION REBUILD TARGET
============================================================

Read the full OrlandoMX_v009_Real_Track_Rebuild_Spec_2026-09-26 before editing. The following is the required operational summary.

S01 — Opening fast straight / low rolling crest
Real: ~0:00-0:12
Goal:
- keep it fast,
- remove dead-flat runway feeling,
- add low coherent rolling elevation,
- narrow the effective riding corridor using shoulders/ruts,
- use a low rounded crest, not a tabletop,
- blend directly into S02.

S02 — First major carved sweeper
Real: ~0:12-0:22
Goal:
- make the corner itself a major physical feature,
- tighten the effective radius,
- lower the inside groove,
- substantially raise the outside half into a broad supporting berm,
- carry braking chop into entry,
- taper bank smoothly on exit,
- physically support multiple lines.

S03 — Corner exit / linked crest sequence
Real: ~0:22-0:34
Goal:
- compact acceleration zone,
- first low roller/crest,
- second stronger rise,
- keep suspension active between them,
- no flat reset,
- begin next crossfall before the runout fully finishes.

S04 — Long bowl-like banked corner
Real: ~0:34-0:46
Goal:
- make this turn the dominant feature,
- reduce any oversized isolated-tabletop character,
- build a long outside berm with varying height,
- deepest/strongest banking near the loaded middle/apex,
- carve 2-3 shallow physical grooves,
- compact the exit toward S05.

S05 — Linked turn complex into clearly airborne jump
Real: ~0:46-0:58
Goal:
- linked direction changes with heavy rut character,
- short gap between turn exit and takeoff,
- progressive jump face,
- stronger upper third,
- rounded lip/short crest,
- real downslope landing,
- landing should already point the bike toward S06.

S06 — Landing / rough acceleration / next berm
Real: ~0:58-1:08
Goal:
- long progressive landing runout,
- coherent acceleration/braking roughness,
- no broad smooth plateau,
- start the next corner banking early,
- build raised outer berm + lower inside line,
- narrow the effective usable lane.

S07 — Major elevated transition / jump
Real: ~1:08-1:18
Goal:
- restore the missing/understated vertical event,
- make it clearly visible from cockpit approach,
- use a longer meaningful face than a low generic roller,
- narrow the corridor using terrain shoulders,
- vegetation/edges should feel closer,
- landing crossfall should feed directly into S08.

S08 — Deep carved berm / compact exit
Real: ~1:18-1:30
Goal:
- treat S07 and S08 as ONE compound jump-to-berm system,
- substantially tighten the corner,
- raise the outside wall relative to the preferred groove,
- create inside/middle/outside viable lines,
- shorten the exit,
- make the next jump approach begin immediately.

S09 — SIGNATURE MAJOR JUMP
Real: ~1:30-1:41
This is the highest-priority single obstacle.

The GoPro shows a large face that dominates the forward view around ~1:34-1:36.
Current v008/v008b is far too low/flat here.

Goal:
- start the approach shortly after S08's berm exit,
- build a long progressive face,
- strengthen the upper face without making an artificial sharp kicker,
- use a rounded, purposeful crest/lip,
- make the face obscure much of the horizon on approach,
- create a distinct downslope landing,
- continue directly into the next direction change,
- reshape the WHOLE sector rather than merely adding height to an existing mound.

A rider familiar with the real track should recognize S09 from the approach alone.

S10 — Landing corridor / tree-side acceleration / berm
Real: ~1:41-1:54
Goal:
- landing should narrow into a corridor,
- add one or two low waves after touchdown,
- vegetation should visually constrain the lane,
- braking chop/crossfall begins before the next berm,
- build the next berm physically.

S11 — Berm exit / fast tree-lined acceleration
Real: ~1:54-2:05
Goal:
- maintain high speed,
- retain subtle longitudinal relief,
- do not flatten the setup,
- use slight crown/crossfall,
- gradually build elevation toward S12,
- preserve useful v008b vegetation placement where it agrees with footage.

S12 — Utility-pole approach / broad ramp
Real: ~2:05-2:16
This is a high-confidence landmark sector.

Goal:
- utility-pole relationship is a hard alignment clue,
- build a rolling/slightly directional approach,
- no flat runway,
- make the ramp broad and long,
- distribute vertical rise over distance,
- rounded crest rather than blocky tabletop,
- proper downhill landing,
- landing should already orient toward S13.

S13 — Post-ramp direction change / second crest
Real: ~2:16-2:28
Goal:
- begin turn geometry during S12 landing/runout,
- build raised outside shoulder/berm and lower inside groove,
- place the second crest close to corner exit,
- make it clearly smaller than S09,
- eliminate neutral flat space between landing -> turn -> crest.

S14 — Rough finishing straight / final sweeper
Real: ~2:28-2:38
Goal:
- coherent directional roughness, not random noise,
- broad worked lines,
- physically bank the final sweeper,
- make final turn less smooth/planar,
- blend seamlessly back into S01 with no height seam, centerline kink, or width reset.
