# v011 changes

This branch starts from the verified v010 package and preserves the previous release.
The requested change is structural: explicit tabletop decks, separate double takeoff and landing masses, and recognizable facility models.

Implemented: separate jump primitives with explicit decks/gaps/landing offsets; eight major feature upgrades; 91 grouped facility/material meshes (17,100 vertices); timber/mesh fence, seating, office/restroom/concession, vehicles, individual oaks and pit roads. Source validation checks the encoded heightfield rather than trusting profile recipes alone.

The normal horizontal route, finish and split positions, pit spawn positions and v010 start-to-T05 logic are preserved. R07/R16 gap details are provisional estimates. EX1/EX2 remain disabled. Native build and ride-test evidence will be added at the next checkpoint.
